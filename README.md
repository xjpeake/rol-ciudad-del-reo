# 🏰 Ciudad del Reo (rol-ciudad-del-reo)

**Sistema de juego de rol y ambientación** creado por **Chris J. Peake**, ambientado en el universo literario de [Mawol](https://www.xjpeake.com).

Ciudad del Reo es el escenario con el que arranca la sección de Juegos de Rol de [xjpeake.com](https://www.xjpeake.com): una ciudad amurallada, cerrada sobre sí misma, con sus propias facciones, calles y secretos.
